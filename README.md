# ქვემო ქართლის რეგიონის ინტერაქტიული გეოგრაფიული ატლასი

**ვებგვერდი:** <https://romakumla.github.io/kvemo-kartli-atlas/>

ქვემო ქართლის რეგიონის თემატური ვებ ატლასი — საქართველოში ერთ-ერთი პირველი ინტერაქტიული რეგიონული გეოგრაფიული ატლასი. მომზადებულია ივანე ჯავახიშვილის სახელობის თბილისის სახელმწიფო უნივერსიტეტის ვახუშტი ბაგრატიონის სახელობის გეოგრაფიის ინსტიტუტში, შოთა რუსთაველის საქართველოს ეროვნული სამეცნიერო ფონდის საგრანტო პროექტის **FR-22-4153** ფარგლებში.

> **English summary.** An interactive thematic web atlas of the Kvemo Kartli region of Georgia, produced at the Vakhushti Bagrationi Institute of Geography (Ivane Javakhishvili Tbilisi State University) under Shota Rustaveli National Science Foundation of Georgia grant FR-22-4153. Built with Leaflet and Chart.js as a static site on GitHub Pages. Code is released under the MIT License, data under CC BY 4.0 (see [LICENSE](LICENSE)).

- **ბუნება** — გეოლოგია, მიწისქვეშა მტკნარი წყლები, მიწისძვრები, მეწყერი და კლდეზვავი, ღვარცოფები, სეტყვა, მეტეოროლოგიური და ჰიდროლოგიური სადგურები, კლიმატური მაჩვენებლები (საშუალო და მაქსიმალური ტემპერატურა, ნალექები, ცხელი დღეები, ტროპიკული ღამეები, ყინვიანი დღეები, სითბური ტალღები, გვალვის ინდექსი), ნიადაგები და ნიადაგწარმომქმნელი ქანები, ტყეები, მცენარეული საფარი, ლანდშაფტები და ანთროპოგენური ლანდშაფტები, აგროკლიმატური დარაიონება

## ტექნოლოგია და სტრუქტურა

სტატიკური საიტია, აწყობის (build) ეტაპის გარეშე: [Leaflet 1.9.4](https://leafletjs.com), [Chart.js 4.4.1](https://www.chartjs.org) და სუფთა JavaScript. გამოქვეყნებულია GitHub Pages-ზე.

```
index.html        საიტის გვერდი
js/main.js        ფენების, ლეგენდების, popup-ებისა და დიაგრამების ლოგიკა
css/style.css     სტილები
libs/             Leaflet და Chart.js (ლოკალური ასლები)
data/*.geojson    თემატური ფენები (WGS 84)
data/muni/*.json  მუნიციპალიტეტების ფენების ატრიბუტები; საზღვრები data/municipalities.geojson-იდან
files/            ლოგოები, თემების ხატულები, გუნდის ფოტოები
```

### მონაცემები

- საწყისი GIS მონაცემები (UTM Zone 38N, shapefile) გარდაქმნილია WGS 84 (EPSG:4326) GeoJSON-ად.
- კოორდინატები დამრგვალებულია 5 ათწილადამდე (~1 მ), ფაილები შეკუმშულია (minified).
- დიდი პოლიგონური ფენები (`forest`, `agrovlimat`, `landscape`, `vegetation`, `crop_zones`) ზომიერად არის გამარტივებული [mapshaper](https://github.com/mbloch/mapshaper)-ით (10 მ ინტერვალი), ერთმანეთის მოსაზღვრე ობიექტების საერთო საზღვრების შენარჩუნებით.

## ლოკალურად გაშვება

ბრაუზერი `fetch()`-ით ტვირთავს GeoJSON ფაილებს, ამიტომ `index.html`-ის პირდაპირ (`file://`) გახსნა არ იმუშავებს — საჭიროა ლოკალური სერვერი:

```bash
python3 -m http.server 8000
# შემდეგ გახსენით http://localhost:8000
```

## მონაცემთა წყაროები

თითოეული ფენის კონკრეტული წყარო მითითებულია ატლასში, ამ ფენის ლეგენდაში. ძირითადი წყაროები:

**სტატისტიკა და მოსახლეობა**
- საქართველოს სტატისტიკის ეროვნული სამსახური (საქსტატი) — მოსახლეობის აღწერები (1989, 2002, 2014), რეგიონული სტატისტიკა
- სოფლის განვითარების სააგენტო
- ადგილობრივი მუნიციპალიტეტებიდან გამოთხოვილი ინფორმაცია

**ბუნება და გარემო**
- გარემოს ეროვნული სააგენტო (მ.შ. გეოლოგიის დეპარტამენტის საინფორმაციო გეოლოგიური ბიულეტენი, 2025)
- E-OBS კლიმატური მონაცემები — Copernicus Climate Change Service
- კავკასიის მიწისძვრების კატალოგი, 2022
- საქართველოს ნიადაგების რუკა, 1:500 000, 2019
- დაცული ტერიტორიების სააგენტო

**ჯანდაცვა**
- დაავადებათა კონტროლისა და საზოგადოებრივი ჯანმრთელობის ეროვნული ცენტრი (ზოონოზური ინფექციები, 1950–2019)

**ეკონომიკა, ისტორია, კულტურა**
- საქართველოს სახელმწიფო ელექტროსისტემა; ღვინის ეროვნული სააგენტო
- საქართველოს საპატრიარქო (საქართველოს ეკლესიის კალენდარი, 2024)
- ქართული საბჭოთა ენციკლოპედია; კ. ხარაძე (1972, 2019); დ. ბერძენიშვილი (2014)
- მუნიციპალიტეტების კულტურის ცენტრები და მუზეუმები

**კარტოგრაფიული წყაროები**
- საქართველოს სსრ ატლასი, 1964
- საქართველოს ეროვნული ატლასი, 2012
- საქართველოს გეოგრაფიული ატლასი, 2018
